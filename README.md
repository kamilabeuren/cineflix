# 🎬 CineFlix

Projeto em desenvolvimento utilizando React, Vite e React Router.

## 📖 Sobre o projeto

O CineFlix é uma aplicação web inspirada em plataformas de streaming de filmes. O objetivo do projeto é praticar conceitos de desenvolvimento Front-End com React, incluindo componentes, roteamento e manipulação de dados.

## 🚀 Tecnologias utilizadas

- React
- Vite
- React Router DOM
- JavaScript
- HTML5
- CSS3

## 🛠️ Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/kamilabeuren/cineflix.git
```

Acesse a pasta do projeto:

```bash
cd cineflix
```

Instale as dependências:

```bash
npm install
```

Execute a aplicação:

```bash
npm run dev
```

O projeto será iniciado em um endereço semelhante a:

```bash
http://localhost:5173
```
